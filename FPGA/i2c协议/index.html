I2C协议

发表于2026-08-27|FPGA
|浏览量:

应用场景

我们常见的 3 种串行通讯协议有：UART、SPI 和 I2C。这次学习整理的是 I2C，目标是把这三种协议都学会，并把代码也写出来，以便日后直接使用

在 FPGA 项目中，有时候需要使用到一些外部设备，比如：Retimer、光模块、FPGA 的System Monitor。而这些外设所使用的接口就是 I2C 接口，所以我需要了解如何设计并使用该接口

目前我仅接触到上面这几种
Retimer 是 Serdes 在进行远距离传输时，对信号进行放大和修复的。可以通过 I2C 读取通道眼图的开眼率 / 写入 Serdes 传输的速率
光模块是为了获取里面的状态信息，看有没有光信号过来、温度是否异常等等
System Monitor 是 FPGA 里面系统监控，用来查看 FPGA 的状态，它对外提供的是 I2C 接口




特性


I2C总线具有以下特性：

  • 只有 2 根总线，数据线（SDA）和时钟线（SCL）
  • 连接到总线的每个设备有唯一的软件地址
  • 多控制器总线，具有冲突检测和仲裁机制
  • 多种速率模式
  • 串行传输，数据传输以 8bit 为单位进行组装




总线协议

SDA 线和 SCL 线


SDA 线和 SCL 线都是双向传输的线，通过上拉电阻连接到供电电压。当总线是空闲状态时，这两根线是处于高电平的。而设备的输出端必须是通过“开漏输出”的方式连接到这两根线上，才能实现“线与”功能


这里补充一些术语

  • 高阻态：不参与电路，即不主动输出高电平，也不主动输出低电平。除非有外部电路驱动它（上拉/下拉电阻），否则就是“悬空”的
  • 悬空：引脚没有任何连接/不受任何驱动。“悬空”的引脚电压无法预测
  • 上拉/下拉电阻：上拉电阻连接到电源，可以将“悬空”的引脚拉到高电平；下拉电阻连接到 GND ，可以将“悬空”的引脚拉到低电平
  • 线与：将多个输出连接在一起


与开漏输出相对的是“推挽输出”，区别在于推挽输出无法实现 I2C 所需要的“线与”，详细的原理可以跳转到参考文献中的引用 2




信号说明

  • Start：数据传输的起始信号，由主机产生
  • Slave Address：要访问的目标地址，由主机产生
  • R/W：访问的读写属性，由主机产生
  • Ack： 主机/从机返回的响应；另外还有一个 NAck 信号
  • Data：主机/从机传输的数据，每次传输 8bit
  • Stop：数据传输的结束信号，由主机产生



数据有效性


I2C 协议对数据的采样是发生在 SCL 为高电平期间，除了起始、停止信号，在数据传输 SCL 为高电平期间，SDA 必须保持稳定，不允许发生变化，只有在 SCL 为低电平时才可跳变



起始信号和停止信号

  • 起始信号：在 SCL 为高电平时，SDA 由高变低
  • 停止信号：在 SCL 为高电平时，SDA 由低变高

如果是单控制器的情况下，控制器在产生 START 之前，判断一下 I2C 总线是否处于空闲状态即可；若是有多个控制器的情况下，每个控制器里面都必须有一套总线状态的判断逻辑
比如：总线空闲时，控制器 A 使用总线并产生 START 信号，此时总线是被控制器 A 所使用，那么控制器 B/C 在空闲时也需要知道此时总线是刚刚发送了 START 信号，总线还处于 Busy 状态。这时控制器 B 和 C 要想使用总线，得需要自己的判断逻辑检测到总线释放了（也就是检测到了 STOP 信号），才能使用




应答信号和非应答信号

  • 应答信号：在 1 个字节传输完成之后（即第 9 个 SCL时钟周期），SDA 信号为低电平；
  • 非应答信号：在 1 个字节传输完成之后（即第 9 个 SCL时钟周期），SDA 信号为高电平；

在发送方发送完 1 个 Byte 之后的第 1 个 SCK 时钟，SDA 线被发送方释放，此时 SDA 因为“开漏输出”的原因，总线会处于高电平，接收方如果收到了数据，就需要把 SDA 线给拉低，以告知发送方“我收到了数据”。如果此时 SDA 线还是处于高电平，则说明接收方没有返回应答信号，这时控制器可以产生 STOP 信号来中止传输或重新生成 START 信号来开始新的传输


以下有 5 种情况会返回 NACK 信号：

  • 总线上不存在目标地址的 Slave ，所以没有 Slave 返回应答信号
  • Slave 端正执行其他功能，所以无法与 Master 建立通信
  • 在传输时，Slave 端接收到无法识别的数据或命令
  • 在传输时，Slave 端不能接收任何数据
  • Master 端在接收到完整的数据时，必须返回 NACK 给 Slave 端

Master 发送 START 信号，此时 I2C 总线被占用，Master 开始发送数据（每次传输数据必须是 1 Byte 写到 SDA 中，并且每个 Byte 后面必须要有应答信号；不限传输了多少个 Byte，数据传输是从 MSB 先开始发送），在第 9 个 SCL 时钟时，时钟还是由 Master 产生，但 SDA 线被释放了，以至于 Slave 可以拉低 SDA 线返回 ACK 信号；

当第 9 个SCL 时钟拉高时，Slave 返回 NACK 信号（SDA 为高电平），此时 Master 可以选择 “ 产生 STOP 信号以终止传输 ” 或者 “ 重新发送 START 信号去开始新一次的传输 ”
