AXI4 架构


AXI 信号描述

握手信号

不管是哪个通道，都有 ready、valid 这两个信号

读/写地址通道信号

Length

写地址通道和读地址通道中的 AxLEN 定义的是==一次突发事务中传输多少个 AxSIZE== ，我们要想传输长度为 N 的数据过去，就把 AxLEN 配置成 N-1

对于 Incr 突发类型，AXI 支持的突发长度为 1~256
对于其他突发类型，AXI 支持的突发长度为 1~16

举例：
AxSIZE = 3‘h1，AxLEN = 7’h6，即一次突发事务传输了 7 个 16 bit 的数据




Size

AxSize[2:0] Bytes in transfer Description
3’h0 1 20 个 Byte，即每次传输的数据量为 8 bit
3’h1 2 21 个 Byte，即每次传输的数据量为 16 bit
3’h2 4 22 个 Byte，即每次传输的数据量为 32 bit
3’h3 8 23 个 Byte，即每次传输的数据量为 64 bit
3’h4 16 24 个 Byte，即每次传输的数据量为 128 bit
3’h5 32 25 个 Byte，即每次传输的数据量为 256 bit
3’h6 64 26 个 Byte，即每次传输的数据量为 512 bit
3’h7 128 27 个 Byte，即每次传输的数据量为 1024 bit



Burst

AXI 协议定义了三种突发类型，分别是：Fix、Incr、Wrap

AxBURST[1:0] Burst Type Description
2’h0 Fix 固定
2’h1 Incr 递增，在一次突发事务中，地址是逐步递增的
2’h2 Wrap 环绕，在一次突发事务中，地址同样是逐步递增，若地址达到上边界，则回到下边界重新开始递增
2’h3 RSV 保留
